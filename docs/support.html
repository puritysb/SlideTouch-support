System requirements

  • macOS 15.1 or later
  • Apple Silicon Mac (M1 or later); Intel Macs are not supported
  • 8 GB RAM or more recommended

Common questions

How do I start editing?

Open a PDF or image, choose Edit Text and double-click an OCR box. Replace the text, then finalize the edit. In 1.2, use Compare & Refine to review the background before exporting a new file.

OCR missed a word or punctuation. What can I do?

Check the recognition languages in Settings and use a higher-resolution source if available. In 1.2, expand the restoration area if fragments remain outside the selected text. Small punctuation and stylized text may still need manual correction.

The restored background looks blurry.

Use a smaller restoration region when possible. In 1.2, compare a texture-preserving correction in Compare & Refine before applying it. Undo an unsatisfactory edit. Photos and repeated patterns do not always restore cleanly.

Can I edit a regular text-based PDF?

SlideTouch is designed for slides where text has been flattened into pixels. It creates replacement layers, rather than editing the original PDF text objects.

Is my original file safe?

Edits are kept in layers and export creates a new file. Keep the source file and export your work before closing. In 1.2, a close warning helps protect unexported edits; it is not a promise of crash recovery.

Which languages are supported?

The 1.1 interface supports English, Korean and Japanese. Version 1.2 adds Simplified and Traditional Chinese. OCR language choices are separate from the interface language and depend on Apple Vision and macOS.

Does the app need the internet?

Document OCR and image processing run locally. Downloads, updates, optional Apple purchases and external support links use the internet.

Why is memory use high?

Image-processing models load on demand and unload when idle. Large pages and high-resolution images can use more memory. Export your work before closing a large document; there is no command to close individual pages.

Do I need to pay or leave a rating?

No. Editing and export are free. In 1.2, Help or Settings offers a voluntary developer tip with an Apple price shown before purchase. Each purchase is a separate one-time charge. It is not a subscription and unlocks nothing. Ratings are optional and independent of tips.

A tip is pending or unavailable.

You can keep editing for free. Check the purchase status in your Apple account before trying again; another purchase may create a separate charge. For an Apple billing issue, contact Apple Support.

Get help

Report a bug on GitHub or contact the developer by email. Include your app version, macOS version, Mac chip, steps to reproduce, and export format. Remove private information from screenshots and sample files. GitHub issues are public.
