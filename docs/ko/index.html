사용 전에 궁금한 점.

편집은 무료인가요?

모든 편집·내보내기 기능은 무료입니다. 1.2 버전의 도움말·설정에서 선택적으로 개발을 응원할 수 있습니다. 구매할 때마다 별도 결제되는 일회성 팁이며, 구독이나 추가 기능은 없습니다.

PDF가 외부로 전송되나요?

OCR와 이미지 처리는 Mac 안에서 이루어집니다. 선택적 결제에는 Apple 결제 서비스를 이용하며, 문서 처리용으로 파일을 전송하지 않습니다.

어떤 배경이든 완벽하게 복원되나요?

아닙니다. 사진·무늬·작은 글자·저해상도 스캔은 수동 보정이 필요할 수 있습니다. 결과를 비교하고 복원 범위를 조정한 뒤 저장하세요.

어떤 Mac과 언어를 지원하나요?

macOS 15.1 이상, Apple Silicon Mac(M1 이상)이 필요합니다. 1.2 앱 화면은 영어·한국어·일본어·중국어 간체·번체를 지원합니다.
