릴리즈 노트

업데이트와 버전별 변경 사항

2026년 9월 13일 상태 확인

1.1.0은 출시된 버전입니다. 1.2.0은 2026년 9월 13일 심사 제출 후 대기 중입니다. 사이트의 1.2 데모는 제출 버전의 화면이며, 해당 변경 사항은 출시 후 사용할 수 있습니다.

1.2.0 · 심사 대기 중

  • 도구 이름을 표시하고 편집 흐름을 정리해 필요한 기능을 찾기 쉽게 개선했습니다.
  • 더 큰 전후 비교 화면에서 복원 범위를 조정하고, 질감 보존 보정 결과를 확인한 뒤 적용할 수 있습니다.
  • 텍스트 편집을 실행 취소하거나 다시 실행할 때 OCR 선택 상태의 일관성을 개선했습니다.
  • 파일 메뉴에서 내보내기를 찾고 Command-Shift-E로 PDF를 내보낼 수 있습니다. 진행 중인 텍스트 수정은 확정하거나 취소한 뒤 내보냅니다.
  • 영어·한국어·일본어에 중국어 간체·번체 화면을 추가했습니다.
  • 도움말·설정에 선택적 일회성 개발 응원을 추가했습니다. 구매할 때마다 별도 결제되며 구독이나 추가 기능은 없습니다. 편집·내보내기는 계속 무료입니다.

1.1.0 · 출시됨

  • 이탈리아어·네덜란드어·폴란드어·튀르키예어·아랍어 등 OCR 언어 선택을 확대했습니다. 실제 인식 가능 여부는 Apple Vision과 macOS에 따라 달라집니다.
  • 텍스트 인식, 배경 복원, 객체 선택의 처리 성능을 개선했습니다.
  • 이미지 처리 모델을 필요할 때 불러오고 유휴 상태에서 해제하도록 개선했습니다.

1.0 · 2026-02-11

Mac App Store 첫 출시. OCR 텍스트 편집, 배경 복원, 객체 선택·이동, 글자 서식·도형, 레이어 기반 실행 취소·다시 실행, PDF·이미지·영상·GIF 내보내기를 제공합니다.
