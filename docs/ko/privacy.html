개인정보 처리방침

2026-09-13

문서 편집은 Mac에서 로컬로 처리됩니다. 문서 내용을 업로드하지 않으며 광고·분석 SDK를 포함하지 않습니다.

열기 또는 드래그 앤 드롭으로 선택한 파일에 접근합니다. OCR은 Apple Vision, 인페인팅·세그멘테이션은 앱에 포함된 Core ML 모델로 Mac에서 실행합니다. 원본 파일은 보존합니다.

선택적인 일회성 개발 응원 결제는 Apple App Store와 StoreKit을 통해 처리되며 네트워크 연결이 필요합니다. Apple이 자체 개인정보 처리방침에 따라 결제를 처리합니다. 개발자는 카드 정보를 받지 않습니다. 앱은 거래를 검증하지만 개발자 서버로 보내지 않습니다. Apple은 판매·정산 보고서를 제공합니다. 편집·내보내기는 무료로 유지됩니다.

설정·최근 파일 참조·평가 요청 중복 방지 기록을 로컬에 저장합니다. 평가 기록은 최초 사용·요청 시각, 앱 버전, 최대 두 개의 파일 경로 해시이며 문서 내용은 포함하지 않습니다. 평가는 Apple 표준 인터페이스를 사용하며 표시 여부는 Apple이 결정합니다. 도움말에서 App Store 평가 페이지를 직접 열 수도 있습니다.

내보낸 파일은 선택한 위치에 남습니다. 앱 삭제만으로 내보낸 파일이나 모든 macOS 컨테이너 데이터가 삭제되는 것은 아닙니다. 로컬 앱 데이터는 macOS에서 별도로 삭제할 수 있습니다.
