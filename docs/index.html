A few things to know.

Is editing free?

All editing and export features are free. Version 1.2 adds a voluntary one-time developer tip in Help or Settings. Each purchase is a separate charge. It unlocks nothing and is not a subscription.

Does my PDF leave my Mac?

OCR and image processing run locally. Optional purchases use Apple’s payment services; your document is not sent for processing.

Will every background look perfect?

No. Photos, patterns, small text, and low-resolution scans can need manual adjustment. Compare the result and refine the restoration area before exporting.

Which Macs and languages are supported?

Requires macOS 15.1 or later and an Apple Silicon Mac (M1 or later). The 1.2 interface supports English, Korean, Japanese, Simplified Chinese, and Traditional Chinese.
